# Balcão – Sistema de Help Desk

Projeto acadêmico: sistema web para abertura e acompanhamento de chamados de suporte técnico.

## Tecnologias
HTML5, CSS3 e JavaScript puro (sem frameworks). Os dados são salvos no navegador com localStorage.

## Funcionalidades
- Abrir chamado com título, solicitante, categoria, prioridade e descrição (com validação)
- Listar chamados ordenados por status e prioridade
- Buscar por título, solicitante ou número; filtrar por status e prioridade
- Ver detalhes, alterar status (Aberto, Em andamento, Resolvido) e consultar o histórico
- Editar e excluir chamados (CRUD completo)
- Painel com contadores, incluindo chamados de prioridade alta pendentes
- Layout responsivo e com modo escuro automático

## Como executar
Abra o arquivo `index.html` em qualquer navegador. Não precisa instalar nada.
